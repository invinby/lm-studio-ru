# LM Studio RU

Расширенный русский интерфейс **LM Studio 0.4.26+4 для Windows**: заполненные словари, перевод захардкоженных подписей и русские даты.

Это неофициальный русификатор сообщества. Здесь находятся переводы и исходники обратимого патчера. Само приложение и модели скачиваются отдельно с [официального сайта LM Studio](https://lmstudio.ai/).

## Что переведено

- Все **1441 ключ** английских словарей этой сборки: чат, настройки генерации и загрузки, сервер, модели, скачивания, первоначальная настройка и общие действия.
- Исправлено **430 отсутствовавших переводов**, включая целиком отключённый русский раздел `shared`.
- **1268 уникальных статических фраз**, использованных в **1714 местах** бандла: кнопки, вкладки, меню, настройки, интеграции, MCP, разрешения, загрузчик моделей, LM Link, голосовой ввод и подписи для экранных дикторов.
- Даты и интервалы: «1 день назад», «2 дня назад», «5 дней назад».

Переводы статических фраз и дат включаются при выбранном русском языке. Другие языки сохраняют штатное поведение. В списке языков русский отображается как «Русский (расширенный перевод)»; это не меняет официальный статус локализации у разработчика.

**Границы покрытия:** наличие перевода всех ключей не означает визуальную проверку каждого экрана. README моделей, содержимое встроенной документации, ответы серверов, пользовательские сообщения, код, системные диалоги и часть экспериментальных/отладочных панелей могут оставаться на исходном языке. Визуальный обход интерфейса для первой версии не завершён. См. [отчёт проверки](docs/verification.md).

## Установка

1. Проверьте версию LM Studio: поддерживается ровно **0.4.26+4** с исходным бандлом, указанным в [манифесте](manifests/0.4.26+4-win32.json).
2. Скачайте этот репозиторий через **Code → Download ZIP** и распакуйте в отдельную папку.
3. Полностью закройте LM Studio, включая значок в трее.
4. Запустите **`install.cmd`**. Права администратора при обычной установке в профиль пользователя не нужны.
5. Откройте LM Studio. Если русский ещё не выбран, переключите язык в настройках приложения.

Установщик сначала использует Node.js, уже поставляемый с LM Studio. Если его нет, нужен [Node.js 22 или новее](https://nodejs.org/). Зависимости npm не нужны, скачивание и выполнение стороннего установщика не происходит.

Для нестандартной папки установки:

```powershell
node patch.cjs apply --app 'D:\Apps\LM Studio'
```

Предварительная проверка без записи файлов и просмотр состояния:

```powershell
node patch.cjs apply --dry-run
node patch.cjs status
```

Перед `apply` и `restore`, включая предварительную проверку в этой версии, приложение должно быть закрыто. `status` доступен и при запущенном приложении.

## Откат

Полностью закройте LM Studio и запустите **`restore.cmd`**. Либо:

```powershell
node patch.cjs restore
```

Откат восстанавливает исходный `main_window.js` байт в байт. Резервная копия остаётся в папке установки:

```text
resources/app/.lm-studio-ru-backup/
  main_window.js.original
  state.json
```

Не удаляйте резервную копию, пока установлен русификатор. Чаты, модели, пароли, настройки и токены патчер не читает и не изменяет.

## Совместимость и обновления

Патчер сверяет версию и SHA-256 всего исходного бандла. На неподдерживаемой сборке или после сторонних изменений установка прекращается до записи файлов. Точный исходный SHA-256:

```text
2a01446f852812338a204adb539bf6e00689faaf61f664f1e38bd13ed6d3adfe
```

Повторная установка той же версии безопасна. Если файлы перевода или патчера изменились, `apply` заново строит результат из проверенной исходной копии и обновляет установленный русификатор. Повторные внедрения кода не накапливаются. Если содержимое совпадает, файлы не перезаписываются.

Обновление LM Studio может заменить бандл и убрать русификацию. Для новой сборки потребуется отдельный проверенный манифест. Если после обновления версия или хеш отличаются, не восстанавливайте старый бандл вручную: используйте штатную переустановку LM Studio либо совместимый выпуск патчера.

Если процесс установки был аварийно прерван и осталась папка `resources/app/.lm-studio-ru-lock`, убедитесь, что патчер и LM Studio не запущены, сохраните резервную копию, затем удалите только пустую папку блокировки и повторите команду. При несовпадении хешей патчер остановится, сохранив данные для диагностики.

## Для разработчиков и переводчиков

```powershell
node --test tests/*.test.cjs
node scripts/validate.cjs
```

- `locales/en/*.json` — английская схема целевой сборки.
- `locales/ru/*.json` — русские словари с сохранёнными ключами, переменными `{{name}}` и тегами.
- `locales/static-ru.json` — проверенный список статических фраз интерфейса.
- `lib/patcher.cjs` — проверка сборки, замена ресурсов, бэкап, атомарная запись и откат.
- `lib/runtime.cjs` — выбор языка для статических фраз и форматирование дат.
- `manifests/` — проверенные версии приложения и точки замены.

Патчер не исполняет приложение для анализа: он извлекает только строковые литералы словарей, а полученный JavaScript проверяет на синтаксис. Изменения применяются к одному локальному файлу приложения. Сетевых запросов и телеметрии у патчера нет.

Если нашли английскую подпись, приложите к issue версию LM Studio, раздел и точный текст подписи. Удалите со скриншота личные сообщения и ключи API.
