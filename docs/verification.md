# Проверка версии 1.0.0

Дата: 26 октября 2026 года. Целевая система: Windows; LM Studio 0.4.26+4.

## Подтверждённые результаты

- 1441 из 1441 английских ключей имеют русские значения с сохранением интерполяций и разметки. Одна намеренно пустая строка для нулевого результата сохранена.
- 1275 фраз в статическом словаре; 1268 из них применены в 1714 местах целевого бандла. Остальные — зарезервированные варианты подписей; их наличие не засчитывается в покрытие бандла.
- Проверены 9 установленных русских модулей и внедрение раздела `shared`.
- Все 10 английских словарей после патча структурно совпадают с исходными.
- Другие JavaScript-чанки renderer не содержат совпадений с используемым списком статических фраз.
- Итоговый бандл проходит разбор `vm.Script` и `node --check`.
- На реальной установке выполнен цикл установка → откат → установка → повторная установка. SHA-256 после отката совпал с исходным.
- Автотесты проверяют хеши, неподдерживаемую версию, повреждённый бэкап, сторонние изменения, блокировку отката, отсутствие записи при dry-run, повторную установку, извлечение строк, сохранение языка, русские даты и валидацию переводов.
- 26 автотестов проходят. Независимое ревью выявило и помогло исправить обновление уже установленного перевода и кеширование подписей при смене языка.
- Для реактивного обновления 543 компонента/хука подписаны на `languageChanged`, а 22 массива зависимостей `useMemo` учитывают язык. Точки изменения получены разбором AST исходной сборки и привязаны к её хешу.

## Ограничения проверки

До изменения ресурсов наблюдался работающий русский интерфейс с английскими подписями поиска моделей. После изменения полный визуальный обход экранов не выполнен: инструмент управления окнами остановился из-за невозможности надёжно определить URL Chrome. Синтаксическая и ресурсная проверки не заменяют визуальную проверку компоновки, переполнения текста и всех интерактивных состояний.

README моделей, документация, удалённый контент, системные диалоги и отладочные панели не входят в гарантию полного перевода. Проект не заявляет «100% всех экранов».
