# Русский интерфейс LM Studio

Подтверждённая пользователем схема: перевод интерфейса установленного LM Studio, установщик с резервной копией и откатом, проверка приложения и публичный GitHub-репозиторий lm-studio-ru.

Целевая сборка: Windows, LM Studio 0.4.26+4. Публикуются собственный патчер и ресурсы локализации, а не бинарники приложения. Базовые переводы взяты из lmstudio-ai/localization (Apache-2.0); атрибуция и лицензия сохраняются.

Патчер проверяет версию, исходный SHA-256 и наличие ожидаемых участков, прежде чем менять файлы. Повторная установка безопасна; откат восстанавливает исходные байты. Проверяются ключи, интерполяции, разметка, синтаксис JavaScript и фактический запуск интерфейса. Строки моделей, пользовательские сообщения, код и API-идентификаторы не переводятся.

Покрытие измеряется отдельно для словарей и строк вне локализации. Полнота всех экранов заявляется только после соответствующей проверки.
